# GitHub Copilot Pilot — Key Questions

1. Workflow: Can you walk me through how code goes from my computer to a working client demo, including where things tend to go wrong?
2. Code review: With Copilot making it easier to produce code quickly, how do we make sure we can review and trust what it produces without slowing the team down?
3. Best practices: Given that we have two junior developers and limited time, what practices should we establish now to avoid creating problems for ourselves later?
4. Deployment and access: What systems do we need access to, who controls that access, and what determines where our code can run?
5. Cost and scaling: What costs or limitations should we understand now, and what would become a problem if we expanded this approach to more developers or larger projects?
